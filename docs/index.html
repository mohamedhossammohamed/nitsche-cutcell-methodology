REPRODUCTION REPORT

Bounded Nitsche Stabilization for Unfitted Finite Element Methods under Sliver Cuts
Exact-Geometry Infrastructure, Verification, and a Preregistered Protocol

An engineering reproduction and verification report accompanying a preregistered evaluation of closed-form stabilization-parameter formulas for symmetric Nitsche methods on unfitted meshes, built on an exact-geometry cut-cell engine (Green's-theorem clipping of circular arcs, affine ellipse reduction, measured-error subdivision fallback).

Honest verdict: infrastructure fully verified and benign-cut validation measured with optimal rates for P1/P2 (L² slopes 1.85 / 3.17, H¹ slopes 0.97 / 2.08, all R² ≥ 0.995). The preregistered sliver sweep and falsification gates H1–H3 are frozen but not yet executed — no stabilization-formula claim is made.
